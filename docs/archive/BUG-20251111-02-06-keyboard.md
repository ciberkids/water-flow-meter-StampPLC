## 1. Bug Summary
- **Observed Behaviour:**  
  1. Physical keyboard Left/Right arrows are still inverted (pressing Left moves the element right and vice versa).  
  2. `(0,0)` does not align with the bottom-left corner of the live preview.  
  3. Clicking the on-screen arrow buttons (Left/Right) in the UI has no effect.
- **Expected Behaviour:**  
  - Left arrow should move the element left, Right arrow right, and `(0,0)` should anchor to the lower-left bezel.  
  - On-screen arrow buttons must mirror the keyboard behaviour.
- **Repro Steps:**  
  1. Open Design tab, select an element, press Left/Right on the keyboard—movement is inverted.  
  2. Set `x=0, y=0` and observe the element not touching the bottom-left corner.  
  3. Click the UI arrow buttons; Left/Right do nothing.

- **Evidence:** Manual repro, existing Playwright tests failing, visual misalignment in preview.
