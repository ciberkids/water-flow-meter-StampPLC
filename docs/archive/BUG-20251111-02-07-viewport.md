## 1. Bug Summary
- **Observed Behaviour:**  
  1. Even with `x=0, y=0`, the preview renders text near the top-right (see screenshot) instead of the bottom-left; origin math is still incorrect.  
  2. Keyboard bindings remain misaligned: pressing Up moves the element left, Down moves right, and Right moves up.  
  3. The viewport movement pad is too tall to sit under the preview; it should be resized to fit between the left column and the colour controls.
- **Expected Behaviour:**  
  - `(0,0)` anchors to the lower-left bezel, max coordinates near the top-right.  
  - Up arrow increases the vertical (X) coordinate, Down decreases it; Left/Right should adjust the horizontal (Y) axis in the expected directions.  
  - The viewport movement UI fits directly beneath the preview without pushing into other sections.
- **Repro Steps:**  
  1. Set any element to `x=0, y=0` and compare to screenshot.  
  2. Press Up/Down/Left/Right; observe incorrect movement.  
  3. Inspect the layout around “Viewport movement” and note it overlaps the right-hand column.

- **Evidence:** Screenshot + current behaviour.
